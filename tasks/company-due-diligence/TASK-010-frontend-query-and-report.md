## 目标

将当前企业查询与报告页面升级为 `CompanyDueDiligenceAgent` 独立工作台。页面保留企业搜索和确认，调查区只提供一个自然语言输入框；用户不选择简单问答、多跳关系或证据检索，前端根据后端返回的 `presentation` 动态展示摘要、业务列表、关系路径、专题报告或完整报告。

系统主智能体和独立工作台复用同一个领域智能体服务与响应组件。

## 页面结构

### 企业上下文区

- 支持企业名称、信用代码或股票代码搜索。
- 展示唯一匹配、多候选、未找到和来源不可用状态。
- 用户确认后建立当前企业上下文。
- 显示标准企业名称和必要识别信息，不要求用户查看或填写内部 `eid`。
- 用户更换企业时明确清空或切换当前调查上下文。

### 调查输入区

- 一个自然语言输入框，支持事实、关系、风险、专题报告和完整尽调要求。
- 快捷问题只填入或提交自然语言意图，不指定底层工具。
- “生成完整尽调报告”按钮提交标准报告意图，并走同一领域智能体接口。
- 高级约束只保留业务可理解项，例如时间范围和是否包含低置信度线索；最多跳数可作为专家设置，默认由系统控制。
- 不显示“简单问答、多跳关系、证据检索”模式。

### 动态结果区

前端读取：

```text
status
understood_request
entities
summary
findings
facts
relations
paths
evidence
sources
data_quality
presentation
task
```

根据 `presentation.type` 渲染：

| presentation | 主要组件 |
| --- | --- |
| `direct_answer` | 摘要、事实来源、数据质量 |
| `summary_with_list` | 摘要、对应业务列表、来源 |
| `relation_result` | 关系结论、路径列表、来源 |
| `risk_summary` | 风险摘要、事件列表、证据、时效 |
| `topic_report` | 专题报告进度、指定主题章节、下载 |
| `full_report` | 完整报告进度、十二章节、下载 |
| `clarification` | 候选企业或最小必要澄清问题 |

`presentation` 是后端已经理解后的展示指令，不是前端重新推断问题类型。

### 关系展示扩展

当前继续使用可读的路径列表，完整显示节点、边、方向、跳数、置信度和来源。后续可以新增交互图组件，直接消费 `entities / relations / paths`：

- 不新增后端查询模式。
- 图与路径列表使用同一数据。
- 图不可用时路径列表仍可完成调查。
- 图形展示不能隐藏低置信度和来源状态。

### 报告任务区

- 自然语言专题报告和报告按钮共用任务卡片。
- 展示总体进度、章节进度和当前运行状态。
- 展示每章事实、证据和数据质量。
- 支持取消任务、失败章节重试、JSON 和 Markdown 下载。
- 专题报告只展示用户要求的主题，完整报告展示标准章节。

## 前端状态

必须明确展示：

- 企业解析中、唯一匹配、多候选、未找到、数据源不可用。
- 意图理解完成、需要澄清、输入不受支持。
- 调查运行中、成功、部分成功、无数据、过期、冲突、失败。
- 报告排队、运行、部分完成、完成、取消和失败。
- 低置信度线索和确定事实使用不同视觉样式。
