## 目标

在现有企业尽调评测前端上增加领域智能体全链路评测，让管理员从企业上下文和用户原话开始，查看实体解析、意图理解、工具计划、Claim Ledger、最终事实、报告范围和 `presentation` 的逐层预测、Golden、指标与首错归因。

## 交付物

- 独立企业尽调评测路由或工作台标签页。
- 数据集、质量运行和性能运行三个区域。
- 总体指标、分类指标、策略对比和历史运行对比。
- 逐题错误、首错归因和报告章节详情。
- 企业、意图、工具计划、输入输出一致性和 `presentation` 详情。
- P50/P95/P99、吞吐、错误率、分段耗时和连接池展示。
- API 封装和前端单元测试。

## 数据集区域

- 数据集名称、版本、checksum 和业务时点。
- 样本数、问题类型和报告 Golden 数量。
- 企业上下文、复合意图、必要/禁止工具和动态展示样本数量。
- 人工复核数和人工复核率。
- 查看样本、筛选类型和下载允许导出的文件。
- 明确区分广东企业 Golden 和 30 家 AkShare 公开基线。

## 质量评测区域

- 选择数据集、问题类型、报告模板和查询策略。
- 启动、取消和查看进度。
- 展示字段、关系、路径、证据、拒答、幻觉、章节完整和时效指标。
- 展示企业解析、意图主题/时间/展示/交付、必要工具召回、无关工具调用、Claim Ledger 一致性和 `presentation` 匹配指标。
- 展示输入主题覆盖率、无关内容率和专题报告范围一致率。
- 按数据域、问题类型、策略和人工复核状态查看分类指标。
- 错误筛选：只看错误、错误类型、首错阶段、企业和章节。
- 详情：企业上下文、用户原话、意图预测/Golden、工具计划、Claim、事实差异、路径差异、缺失来源、presentation 差异和运行耗时。

## 性能评测区域

- 选择场景、安全模式、并发、持续时间和数据集。
- 真实只读库模式显示管理员确认和风险提示。
- 展示 P50/P95/P99、吞吐、成功率、超时率和错误率。
- 展示身份、池等待、MySQL、Neo4j、Milvus、LLM 和组装耗时。
- 展示连接池大小、签出、等待、溢出和超时。
- 对比两个运行的代码版本、数据版本和参数。

## 实现步骤

1. 在既有企业尽调 API 文件中增加评测分组。
2. 使用后端契约构建 mock，先完成页面和交互。
3. 复用现有任务进度模式，统一处理排队、运行、终态和取消。
4. 指标卡和图表使用 `base.css` 与既有图表色板。
5. 逐题详情保留原始结构化差异，不只展示自然语言摘要。
6. 对真实库性能运行增加二次确认和硬参数提示。
7. 导出由后端生成，前端只下载，不重新计算指标。
8. 长列表使用分页或虚拟化，避免一次渲染全部样本。
9. 新指标只展示后端聚合结果，前端不自行重算意图或一致性得分。
